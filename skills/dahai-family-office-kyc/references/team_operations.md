# 团队架构与内部协作流程

> 来源：《平安人寿家办客户经营手册》第17章
> 涵盖陪访资源申请流程、家办会员升级路径、方案设计协作机制等内部操作规范。

---

## 一、陪访资源申请流程

### 1.1 陪访类型与预约要求

| 陪访类型 | 预约提前期 | 适用场景 | 申请方式 |
|:---|:---|:---|:---|
| **线上陪访** | 提前2个工作日 | 高价值客户初步沟通、异地客户初访 | 通过机构集中上报需求至家办总部 |
| **线下当地陪访** | 提前5个工作日 | 本地高净值客户深度面谈、方案呈现 | 通过机构集中上报需求至家办总部 |
| **线下异地陪访** | 提前7个工作日 | 异地重要客户专项服务、家族信托方案沟通 | 通过机构集中上报需求至家办总部 |

### 1.2 申请前准备

顾问在申请陪访前须完成三项准备：

**第一，客户信任基础**——已获得客户基本信任，客户对信托有初步兴趣而非完全排斥。

**第二，充分KYC**——能清晰描述客户的家庭结构、资产状况和核心诉求。建议携带客户已填好的KYC需求分析表和家庭关系图参加沟通会。

**第三，业务落地追踪计划**——明确陪访后的跟进步骤和时间节点。

### 1.3 陪访中的角色分工

| 角色 | 职责 | 行为要点 |
|:---|:---|:---|
| **顾问** | 主持人 | 负责开场介绍、引导话题、衔接问答，不能把客户丢给专家后自己沉默 |
| **信托专家/团队长** | 专业背书 | 提供权威解答、架构设计建议、法税专业意见 |

### 1.4 陪访后跟进

- 陪访结束后**24小时内**向客户发送总结
- 安排下一步行动时间节点
- 每落地一单信托，额外赠送1次"一案到底"陪谈服务

## 二、平安家办四级会员体系与升级路径

### 2.1 会员准入标准

| 会员级别 | 新单保费门槛 | 新老单合计门槛 | 核心定位 |
|:---|:---|:---|:---|
| **准会员** | 600万元 | 688万元 | 入门体验，感知家办价值 |
| **正式会员** | 1000万元 | 1888万元 | 深度服务，解锁家族信托完整功能 |
| **尊贵会员** | 3000万元 | 4388万元 | 全权益覆盖，享受高阶定制服务 |
| **至尊会员** | — | 1亿元 | 顶级尊享，总监天团专属配置 |

**向下兼容原则**：高级别会员自动享有低级别会员的全部权益。

### 2.2 六维十六项权益对照

| 权益维度 | 权益项目 | 准会员 | 正式会员 | 尊贵会员 | 至尊会员 |
|:---|:---|:---|:---|:---|:---|
| 财富 | 信托服务 | 保险金信托、慈善信托 | +家族信托、外籍受益人定制、保护人设立、分配条款定制 | +股权/债权/不动产装入、专家陪访 | +家族宪章、总监天团陪访、管理费定制 |
| 财富 | 法税咨询 | 基础 | 升级 | 升级 | 尊享 |
| 财富 | 基金定制 | 无 | 有 | 有 | 有 |
| 财富 | 上市辅导 | 无 | 无 | 有 | 有 |
| 健康 | 高端医疗 | 基础 | 升级 | 升级 | 尊享 |
| 养老 | 高端养老 | 基础 | 升级 | 升级 | 尊享 |
| 传承 | 教育规划 | 有 | 有 | 有 | 有 |
| 传承 | 职涯规划 | 有 | 有 | 有 | 有 |
| 传承 | 家风建设 | 无 | 有 | 有 | 有 |
| 传承 | 接班辅导 | 无 | 无 | 有 | 有 |
| 文娱 | 城市会客厅 | 有 | 有 | 有 | 有 |
| 文娱 | 圈层活动 | 有 | 有 | 有 | 有 |
| 文娱 | 观影观赛 | 无 | 有 | 有 | 有 |
| 文娱 | 名企探访 | 无 | 无 | 有 | 有 |
| 文娱 | 艺术鉴赏 | 无 | 无 | 有 | 有 |
| 公益 | 慈善信托/公益活动 | 有 | 有 | 有 | 有 |

信托服务作为三大"尖刀"权益之一，在不同会员级别上呈明显功能递进：
- **准会员**：可设保险金信托和慈善信托
- **正式会员起**：可设家族信托，获得外籍受益人定制、保护人设立和分配条款定制
- **尊贵会员**：可装入股权、债权、不动产并享受专家陪访
- **至尊会员**：可定制家族宪章、享受总监天团服务

### 2.3 升级沟通话术

与客户沟通家办权益时，建议将升级作为"附加价值"呈现：

- 客户投保达**600万元**时："您现在已经达到了平安家办准会员标准，可以享受保险金信托、慈善信托和教育规划等权益。"
- 追加至**1000万元**时："从这一刻起，您可以正式设立家族信托，设置保护人监督信托运作。"
- 追加至**3000万元**时："您现在可以装入股权、债权、不动产，并享受专家一对一陪访服务。"

## 三、方案设计协作机制

### 3.1 内部协作流程

```
代理人（面访+KYC信息采集）
  ↓
AI技能辅助（需求分析+缺口量化）
  ↓
信托专家介入（架构设计+合规审查） ← 触发条件：客户≥1000万或需求复杂
  ↓
法税顾问（特殊架构论证+跨境税务规划） ← 触发条件：涉及股权/外籍/复杂传承
  ↓
方案呈现 → 客户决策 → 签署落地
```

### 3.2 各阶段协作方

| 阶段 | 主导方 | 协作方 | 交付物 |
|:---|:---|:---|:---|
| KYC采集 | 代理人 | AI辅助 | 《客户信息采集表》 |
| 需求分析 | 代理人+AI | — | 《需求分析报告》 |
| 方案设计 | 信托专家 | 代理人协助 | 《信托架构方案书》 |
| 合同起草 | 法律团队 | 信托专家 | 定稿版信托合同 |
| 签署双录 | 信托经理 | 代理人协调 | 签署完成的合同+双录记录 |
| 资金交付 | 信托经理 | — | 资金到账确认 |
| 信托成立 | 投配团队 | — | 信托成立通知书 |

### 3.3 专家介入触发条件

| 场景 | 必须专家介入 | 建议专家介入 |
|:---|:---|:---|
| 客户可投资资产≥1000万 | ✅ 家族信托架构设计 | — |
| 涉及股权装入 | ✅ 合规性论证+架构可行性分析 | — |
| 涉及外籍受益人 | ✅ 跨境税务规划+FGT/祖母信托架构 | — |
| 涉及债权装入 | ✅ 法律合规审查 | — |
| 客户可投资资产500-1000万 | — | ✅ 保险金信托3.0方案设计 |
| 家庭结构复杂（再婚、多子女） | — | ✅ 分配方案设计+保护人设置 |
| 客户申请陪访 | — | ✅ 信托专家/团队长 |

## 四、服务时效标准

| 服务项目 | 时效标准 | 备注 |
|:---|:---|:---|
| 保险金信托设立 | 最快2小时 | 材料齐全、配合顺畅 |
| 家族信托设立 | 标准型最快7天 | 投配时效平均2天，分配时效平均2天 |
| 家族信托定制型 | 通常2至4周 | 涉及股权/特殊架构需更长 |
| 方案设计 | 3至7个工作日 | 从需求沟通到方案输出 |
| 合同起草确认 | 1至2周 | 数轮沟通定稿 |
| 陪访预约（线上） | 提前2个工作日 | 通过机构集中上报 |
| 陪访预约（线下当地） | 提前5个工作日 | — |
| 陪访预约（线下异地） | 提前7个工作日 | — |

## 六、顾问日常工作规范

### 6.1 面访前准备
- [ ] 回顾客户历史信息和上次沟通记录
- [ ] 准备KYC需求分析表和家庭关系图模板
- [ ] 温习五大异议速查卡
- [ ] 确认是否需申请陪访支持

### 6.2 面访中执行
- [ ] 按"人财情事"四维度引导信息采集
- [ ] 用委婉话术询问敏感信息（资产、婚姻等）
- [ ] 适时插入场景化案例引发共鸣
- [ ] 记录客户核心关切和情感诉求

### 6.3 面访后复盘
- [ ] 使用AI技能完成信息整理和需求分析
- [ ] 标注信息完整度和缺失项
- [ ] 制定下次跟进计划和追问方向
- [ ] 如需专家支持，及时提交陪访申请

### 6.4 持续服务
- [ ] 养老和关爱场景客户保持高频轻量接触
- [ ] 每季度回顾更新KYC需求分析表
- [ ] 已落地项目标注完成日期，形成完整客户服务档案
- [ ] 关注客户家庭结构变化，及时调整方案
