# 高客KYC操作指南

> **采集流程提示**：本文件提供"人财情事"四维度清单和客群画像数据。实际采集时，遵循 `full-guide.md` 3.2 节的"先总述后补缺"模式——先让代理人自由描述已知的全部信息，再对照本清单精准追问缺失项，不要逐轮一问一答。

## 一、"人财情事"四维度深度KYC

### 1.1 "人"维度——家庭结构与关系

**家庭成员构成**
- 家庭成员清单（本人、配偶、子女数量及年龄、父母健在情况、孙辈）
- 家庭结构类型判定：核心家庭/主干家庭/联合家庭/单亲家庭/再婚家庭/丁克家庭
- 婚姻状况：初婚/再婚/离异/丧偶（再婚家庭需特别关注前婚子女）
- 子女婚育情况：已婚/未婚/已育/未育（子女即将结婚是婚前隔离场景触发信号）
- 多段婚姻历史（涉及非婚生子女需特别处理）
- 健康关注度：体检习惯、就医偏好（公立/私立/海外）、家族病史
- 家庭决策模式：男主外女主内/共同决策/AA制（决策人是谁至关重要）

**关键发现点**
- 子女适婚年龄（25-35岁）→ 婚前隔离需求
- 多段婚姻/非婚生子女 → 传承复杂性增加
- 丁克家庭 → 养老信托+慈善信托切入点
- 家庭关系紧张 → 保密条款+分类受益人需求

### 1.3 "情"维度——情感诉求与隐性焦虑

**情感诉求清单**
- 最在意的人是谁？（决定受益人设计优先级）
- 对子女的期望（独立奋斗/接班企业/自由发展）
- 对配偶的承诺（养老保障/生活品质的维持）
- 对父母的孝心（养老医疗/生活质量）
- 对孙辈的关爱（教育/成长/未来保障）

**隐性焦虑识别**
| 焦虑信号 | 对应场景 | 切入话题 |
|:---|:---|:---|
| "现在离婚率太高了" | 子女婚前隔离 | "给小两口既有面子又有里子" |
| "企业最近要贷款" | 家企债务隔离 | "签担保是为企业负责，做信托是为家人负责" |
| "我走了以后孩子怎么办" | 财富精准传承 | "信托可以把您的意愿变成保密的制度安排" |
| "孙子是我带大的" | 隔代关爱 | "这份爱可以跨越时空，制度化地传递" |
| "企业以后要交给谁" | 二代接班 | "股权不被继承分割，接班人有制度保障" |
| "住养老院会不会被骗" | 养老规划 | "信托+养老社区直付，制度化的养老保障" |

### 1.4 "事"维度——风险事件与触发因素

**生命周期阶段与风险地图**

| 年龄段 | 核心风险 | 需求优先级 |
|:---|:---|:---|
| 30-40岁 | 重疾致收入中断、意外身故、房贷断供 | 基础保障为主 |
| 40-50岁 | 重大疾病、身故断流、子女教育金缺口 | 大额寿险+保险金信托 |
| 50-60岁 | 经营风险传导、子女婚姻致财富外流、传承启动 | 家企隔离+定向传承+信托 |
| 60-70岁 | 重疾高发、护理费用、身后安排 | 养老信托+隔代传承 |
| 70岁+ | 行动力下降、传承紧迫、方案简洁化 | 传承方案落地执行 |

**近期触发因素**
- 身边案例（朋友离婚分产/企业主破产/同事猝死）
- 企业融资需求（银行要求连带担保）
- 健康状况变化（重大疾病/手术/体检异常）
- 重大生活事件（子女结婚/再婚/退休/孙辈出生）
- 政策影响（金税四期、新公司法）

## 三、一问一答对话实战指引

### 3.1 对话原则

**核心模式：AI问1个 → 代理人答1个 → AI问下1个 → 代理人答下1个**

- AI每次只问**1个问题**
- 问题简短自然（15字以内为佳）
- 根据上一个回答，灵活调整下一个问题
- 不给代理人"问卷清单"式的压力
- 像朋友聊天一样，慢慢收集信息

**禁止的做法**：
- ❌ 一次性列出4-6个问题让代理人逐一回答
- ❌ 给代理人发"问题清单"让对方自己填
- ❌ 一次性追问太多，让代理人感到压力

### 3.2 各维度一问一答示例

#### "人"维度对话示例（带温度版）

```
AI: "今天见的客户怎么称呼？认识多久了？"
代理人: "姓王，叫王姐就行，认识两三年了，老客户转介绍的"
（先问称呼+关系——让客户画像有温度）

AI: "王姐多大年纪？家里几口人？"
代理人: "55岁，家里三口人"
（2个简单事实一起问）

AI: "儿子多大了？听说快结婚了？"
代理人: "28岁，下个月结婚"
（用'听说'过渡——自然带出，不像审问）

AI: "婚姻状况呢？"
代理人: "她离异多年，没再婚"
（简短直接，不啰嗦追问细节）

AI: "王姐平时家里大事谁拿主意？她自己还是和前夫/家人商量？"
代理人: "她自己做主，企业也是她创立的，挺有主见的人"
（'谁拿主意'比'谁管钱'更委婉——先铺垫再深入）
```

#### "财"维度对话示例（带铺垫版）

```
AI: "王姐家里大概多少可投资资产？方便问吗？"
代理人: "她说大概500万左右"
（加'方便问吗'给客户台阶——即使不说也不尴尬）

AI: "这500万大概是什么构成？现金多还是房产多？"
代理人: "现金200万，理财200万，年金险100万"
（用'大概'降低精确度要求——不用精确数字）

AI: "她那家企业值多少钱她自己有估过吗？"
代理人: "她说企业也算的话大概1500万"
（用'她自己有估过'——不是我问的，是她自己说的）

AI: "家里有没有负债？房贷或者企业贷款？"
代理人: "没有，早还清了"
（负债和贷款一起问——关联性强，自然过渡）

AI: "之前买过什么保险？"
代理人: "就一份年金险，别的没了"
（保险问题是中性问题，可以直接问）

AI: "企业最近有贷款方面的安排吗？银行那边有接触？"
代理人: "没有，她说不想借了"
（用'银行那边有接触'替代'有没有贷款'——更委婉）
```

#### "情"维度对话示例

```
AI: "她今天聊的时候最担心什么？"
代理人: "她说最怕儿子以后离婚，钱被分走"
AI: "对儿媳怎么看？"
代理人: "她觉得儿媳家境普通，有点担心"
AI: "她最在意的人是谁？"
代理人: "肯定是她儿子，还有一个孙子快出生了"
AI: "她提到朋友离婚的事了吗？"
代理人: "提了，说她有个闺蜜离婚分了一半财产"
```

#### "事"维度对话示例

```
AI: "企业现在谁在管？"
代理人: "交给合伙人了，她半退休"
AI: "儿子在她公司干吗？"
代理人: "大儿子在公司做副总，小儿子在国外读书"
AI: "小儿子想接班吗？"
代理人: "不想，说想搞IT"
AI: "她父亲还在吗？"
代理人: "在，78岁了，需要人照顾"
```

### 3.3 什么时候停止追问

**停止信号**（满足任一即停）：
- 代理人说"今天就了解到这些"
- 连续问了8-10个问题
- 信息量达到该轮目标
- 代理人表示要结束

**停止时的操作**：
1. 总结已采集信息
2. 告知完整度
3. 约定下次重点
4. 保存进度

### 3.4 分次采集完整度标准

| 阶段 | 完整度 | 可输出成果 |
|:---|:---|:---|
| 初访后 | 40-60% | 《信息采集表（初版）》 |
| 二访后 | 60-80% | 《需求分析报告（初版）》，标注不确定性 |
| 三访后 | ≥80% | 完整三份报告 + 《综合配置建议书》 |

### 3.5 常见问题处理

**Q：客户不愿意透露资产具体数字怎么办？**
A：先问量级区间（100万/500万/1000万/5000万以上），不强求精确数字。关键是判断客户属于哪个层级，决定后续可推荐的方案范围。

**Q：一问一答太慢了，能不能快点？**
A：可以。如果代理人一次性给了多个信息，AI可以直接进入下一个相关维度的问题，不用死磕一个一个来。节奏由对话自然决定。

**Q：客户说"你先把方案做好给我看"但信息还不完整？**
A：坦诚回应："我很乐意做方案，但如果信息不完整，方案可能不适合您。就像医生没听完症状就开药，您敢吃吗？再给我10分钟，确认几个关键数字，方案会准得多。"

## 四、家庭关系图绘制指南

### 4.1 绘制方法

1. **确定中心**：以委托人（客户本人）为中心
2. **分层展开**：
   - 第一层：配偶
   - 第二层：子女（按年龄排序，标注婚育状况）
   - 第三层：父母、孙辈
   - 第四层：兄弟姐妹（如有重要关联）
3. **标注关键信息**：
   - 每人的年龄/健康状况
   - 婚姻状况（初婚/再婚/离异）
   - 经济独立性（独立/依赖/部分依赖）
   - 与企业关系（是否参与经营/持股）

### 4.2 信息发现

通过家庭关系图可发现：
- 潜在受益人数量和关系
- 婚姻风险点（多段婚姻、非婚生子女）
- 代际传承链条
- 家企混同风险（家族成员是否参与企业）
