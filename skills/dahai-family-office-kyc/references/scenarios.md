# 五大场景化解决方案

## 场景一：婚姻风险隔离

### 1.1 子女婚前财产隔离

**典型案例：刘女士200万增额寿+保险金信托**

刘女士55岁，企业主，离异多年，独子即将结婚，未婚妻已怀孕。

**核心诉求**：儿子婚前财产严格隔离 → 从儿子到孙子传承链条畅通 → 儿媳不能自动获得财产份额

**方案设计**：
- 200万×10年增额终身寿险+保险金信托
- 刘女士作为委托人和投保人，儿子为被保险人
- 身故受益人变更为平安信托
- 信托受益人：刘女士本人、儿子、尚未出生的孙辈（潜在受益人）
- 分配条款：儿子每半年领取30万元，明确约定为**个人财产**，不纳入夫妻共同财产

**设计要点**：
1. 时间差运用——保单10年缴费期，在缴费期内即可锁定信托条款
2. 个人财产条款——根据《民法典》第1063条，明确约定为受益人个人财产
3. 潜在受益人——孙辈尚未出生也可预设，出生后凭出生证明添加

**顾问式切入**：先评估保障，再谈架构

> "刘女士，您儿子即将结婚，这是喜事。咱们可以先看看您家庭的基础保障是否已经充足——您和儿子的重疾险、寿险是不是都配好了？在保障充足的前提下，如果您确实担心婚前财产隔离的问题，我可以为您介绍保险金信托这个选项。但这不是必须的，完全取决于您的担忧程度和意愿。信托可以实现的是：在不伤害小夫妻感情的前提下，把给儿子的生活补贴约定为他的个人财产。您觉得这个担忧是不是已经存在？"

### 1.2 再婚财产隔离

**典型案例：张先生5000万现金+6888万保单家族信托**

张先生47岁，影视行业，离异育有一女12岁，即将再婚，父亲80岁高龄。

**方案设计**：
- 5000万现金设立家族信托（鸿图系列）→ 再婚财产绝对隔离
- 5000万保额定额终身寿险+1888万增额终身寿险 → 杠杆放大+传承
- 投保人变更为信托公司（3.0模式）→ 三权完全分离
- 父亲：每季度15万生活金（可对接臻颐年养老社区）
- 女儿：学业支持金+婚嫁祝福金+生育奖励金+55岁后每年50万生活金

**顾问式切入**：先了解真实担忧，再匹配工具

> "张先生，您即将再婚，这是人生新阶段。我想先了解：您目前最担心的是什么？是第一次离婚分掉财产的经历重演，还是担心女儿的未来保障，还是父亲养老的问题？不同的担忧对应不同的工具——有的用保险就能解决，有的确实需要信托的隔离功能。信托就像一个'法律保险箱'，但放不放进去、放多少，完全由您决定。咱们先把您的担忧梳理清楚，再看什么工具最合适。"

## 场景二：家企债务风险隔离

### 2.1 阻断经营风险向家庭传递

**典型案例：王先生300万现金+3000万保单家族信托**

王先生50岁，企业主，企业扩张期，需向银行贷款3000万，银行要求个人连带担保。

**方案设计**：
- 300万现金+3000万定额终身寿险（120万×10年缴费）
- 三重保护：家企隔离+杠杆放大+定向滴灌
- 子女：18岁起每年30万生活金+教育金+医疗金+紧急备用金
- 配偶：委托人去世后每季度6万生活金

**核心逻辑**："签担保是为企业负责，做信托是为家人负责——两者不矛盾，而且后者更重要。但前提是您的家庭保障已经充足。"

> "王总，您现在要在事业上再搏一把，但做企业没有100%的确定性。如果家庭的寿险保障已经配足了，我们可以进一步探讨用信托给家人设一条'底线安全线'——这不是对企业没信心，而是给家人的一份确定性。如果保障还没配足，我建议咱们先把基础保障筑牢，再根据您的意愿决定是否升级。"

### 2.2 债权家族信托

**适用对象**：存在家企资金混同历史的企业家

**五大功能**：
1. **家企防火墙**：信托成为借贷主体，债权与个人资产隔离
2. **财务规范化**："其他应付款-股东借款"→"金融机构借款"，提升信用评级
3. **税务优化**：信托公司可开具利息发票，企业可税前扣除
4. **隐私保护**：债权信息不对外公开，受益人间相互保密
5. **传承衔接**：债权本息回流信托，通过保险和分配机制实现全家养老保障

**金税四期紧迫性**："把过去'不清不楚'的借款变成一笔'清清楚楚'的金融机构贷款——公司有利息发票可以抵税，您个人的资产多了层隔离保护。"

## 场景三：财富精准传承

### 3.1 多子女差异化传承

**典型案例：S总三子分类设计**

S总退休企业高管，三子情况各异：长子事业有成、次子稳定、小儿子28岁无业。

**方案设计**：
- 家族信托，受益人分为A/B/C三类
- A类（长子及后代）：29% — 侧重教育金+婚嫁金激励
- B类（次子及后代）：19% — 同A类标准
- C类（小儿子及后代）：各10% — 基本生活金较高但附加"参加工作满一年"条件
- **相互保密**：每位受益人仅知道自己的分配内容

**分类设计要点**：
- 基础保障+行为激励双层结构
- 动态调整机制（完成目标奖励/不良行为暂停）
- 潜在受益人（新生儿出生后添加）

### 3.2 上市公司股票传承

**典型案例：L女士2亿股票+一致行动人安排**

L女士与女儿、女婿共同控制估值100亿上市公司，年事已高。

**方案设计**：
- "家族信托+有限合伙"双层架构
- 家族信托作为LP（有限合伙人）→ 享有分红收益
- L女士100%控股公司作为GP（普通合伙人）→ 掌握经营权
- 有限合伙持有上市公司股票
- 配合一致行动人协议→ 确保股东大会表决权集中

**核心价值**：
- 所有权集中：股权不登记在自然人名下，不被分割/冻结/继承
- 经营权把控：GP拥有完全经营管理权
- 受益权共享：家族成员共享经济收益但不涉经营

### 3.3 反面教材

**杉杉股份**：郑永刚持股51%控制杉杉股份，突发心脏病离世，未留遗嘱/信托。股权经夫妻共同财产析产+法定继承两轮分割，接班人郑驹仅获约5.1%。周婷大闹股东大会→2024年接任董事长→2025年破产重整→2026年郑氏家族彻底出局。**百亿帝国， founder 离世不到两年即崩盘。**

**核心教训**：如果提前设立股权家族信托，51%股权永远在信托架构内，不会因身故被分割。

## 场景四：二代接班与股权传承

### 4.1 股权家族信托架构

**五层架构要素**：

| 层级 | 角色 | 功能 |
|:---|:---|:---|
| 家族信托（上层） | 财产持有与分配主体 | 信托财产独立性，免受债务和继承分割 |
| 有限合伙企业（中层） | 股权持股平台 | 股权不登记在自然人名下 |
| GP公司（控制端） | 经营权实际控制方 | 对合伙企业的完全经营管理权 |
| 目标公司（底层） | 实际经营实体 | 产生利润并向股东分红 |
| 受益人（家族成员） | 经济收益享有方 | 共享家族财富但不干预经营 |

**GP公司控制权安排**：
- GP可由委托人100%控股的公司担任
- GP公司股权继承可提前在章程中安排
- 委托人去世后由指定接班人自动接任GP
- 制度化的接班安排，不依赖遗嘱或口头承诺

### 4.2 杉杉股份模拟方案

假设郑永刚2018年设立股权家族信托：
- 家族信托作为LP → 向有限合伙企业注资
- 郑永刚100%控股公司作为GP → 持股宁波青刚51%→间接控制杉杉股份
- 受益人包括郑驹和周婷及其子女
- GP公司股权继承：郑永刚身故后由郑驹自动接棒

**效果**：股权不分割、控制权稳定、受益平衡、经营连续、家族永续。

## 场景五：养老规划与隔代关爱

### 5.1 养老信托

**典型案例：高女士（丁克家庭）**

高女士65岁，退休企业集团高管，与丈夫无子女。

**方案设计**：
- 500万年金保险+500万现金 → 家族信托总规模1000万
- 养老服务机构直付：信托定期直接向养老社区支付费用
- 意定监护公证：清醒时指定信任的监护人
- 第三方监察人：监督信托财产使用和养老机构服务质量
- 亲属感谢金+公益捐赠

**四大功能模块**：养老账户保险箱+服务支付直通车+意定监护+监察人

**与臻颐年养老社区联动**：
- 系统直连支付便利
- 服务质量制度保障
- 集团资源协同整合

### 5.2 隔代关爱信托

**典型案例：李女士300万现金+700万保单给孙子**

李女士69岁，退休国企高管，与13岁孙子感情极深。

**方案设计**：
- 300万现金+700万保单（年金险）→ 家族信托1000万
- 受益人仅有孙子一人
- **递进式分配**：
  - 参加工作：每半年9万
  - 结婚：每半年12万
  - 第一个孩子出生：每半年18万
  - 第二个孩子出生：每半年24万
- 双保护人架构：第一任爷爷 → 第二任孙子本人（成年后）

**核心设计**：金额递增匹配人生责任——工作→结婚→生子，金额逐步增加（9→12→18→24万/半年）。

**情感价值**：法理情的完美结合——法（精准传承）+理（递进设计）+情（跨越时空的爱）。

### 5.3 特需关爱信托

为身心障碍人士（自闭症、脑瘫、智力障碍等）设立的长期照护信托。
- 父母在世时将财产置入信托
- 指定专业照护机构或信任监护人
- 信托财产定向用于生活费、医疗费、康复费、照护费
- 父母双亡后仍持续保障
- 常与保单组合使用（终身寿险→身故金进入信托→孩子终身照护资金池）
