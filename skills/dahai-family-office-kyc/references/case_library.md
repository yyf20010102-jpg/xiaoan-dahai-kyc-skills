## 一、婚姻风险隔离场景

### 案例1：刘女士——儿子婚前财产隔离（200万增额寿+保险金信托）

**【客户背景】** 刘女士55岁，白手起家的企业主，离异多年，独子即将结婚，未婚妻已怀孕。

**【核心诉求】**
1. 儿子的婚前财产必须与婚后财产严格隔离
2. 从儿子到孙子的传承链条要畅通无阻
3. 儿媳不能因为婚姻关系自动获得财产份额

**【方案设计】** "200万×10年增额终身寿险+保险金信托"
- 刘女士作为委托人和投保人，儿子为被保险人
- 身故受益人变更为平安信托
- 受益人：刘女士本人、儿子、尚未出生的孙辈（潜在受益人）
- 分配方案：儿子每半年可领取30万元基本生活金，条款中明确写明该笔款项为儿子**个人财产**，不纳入夫妻共同财产；为未来的孙辈预设教育金、婚嫁金和创业金

**【设计要点】**
1. **时间差运用**：增额终身寿险按"年交保费×缴费期"计算规模，200万×10年=2000万，在缴费期内即可满足信托准入门槛
2. **个人财产条款**：根据《民法典》第1063条，信托分配条款中必须明确约定"分配给受益人的生活金为受益人个人财产，不纳入夫妻共同财产"
3. **潜在受益人**：平安信托支持设置"潜在受益人"，孩子出生后凭出生证明添加为正式受益人

**【顾问话术参考】** "刘女士，您儿子即将结婚，这本来是喜事。但咱们做父母的，打拼了一辈子，肯定希望这些钱能稳稳当当地传到儿子和孙子手里，对吧？信托有一个特别的功能，可以在不伤害小夫妻感情的前提下，把您给儿子的生活补贴明确约定为他的个人财产，离婚分不走。而且孙子一出生就能成为受益人，相当于您现在就给未出生的孙辈准备了一份'终身礼物'。"

### 案例2：张先生——再婚财产隔离（5000万现金+6888万保单家族信托）

**【客户背景】** 张先生47岁，影视行业从业者，离异多年，育有一女12岁分给前妻，父亲80岁高龄，即将再婚。

**【核心诉求】**
1. 前车之鉴——第一次离婚分掉了不少财产，再婚前必须做好财产隔离
2. 愧疚心理——对女儿有愧疚，希望留一笔专属资金保证女儿一辈子无忧
3. 孝心——确保父亲的晚年生活品质
4. 自身保障——工作强度大，身边有同事猝死案例

**【方案设计】** "家族信托全场景方案"，总规模超1.1亿元：
- **第一部分**：5000万元现金作为婚前财产设立家族信托（鸿图系列），实现再婚前的财产绝对隔离
- **第二部分**：配置5000万保额定额终身寿险（分10年缴，年缴约200余万）+ 1888万增额终身寿险，一并装入信托，投保人变更为信托公司（3.0模式）
- **分配方案**：父亲每季度领取15万元生活金；女儿设置学业支持金、婚嫁祝福金、生育奖励金、消费引导金、紧急备用金等全方位保障，55岁后每年50万元养老生活金

**【设计要点】** 婚前财产的绝对隔离首选家族信托而非保险金信托——保险金信托管理的是"未来才会赔付的保单资产"，再婚隔离需要将"现在已经持有的现金资产"在法律上与婚后财产彻底切割。将投保人变更为信托公司（3.0模式），实现了"三权完全分离"。

**【顾问话术参考】** "张先生，您这次再婚，我们既要让您和新太太过得安心，也要让您觉得对得起女儿和父亲。信托就像一个'法律保险箱'，您婚前积累的财富放进去，仍然由您控制怎么分、分给谁，但法律上它已经是独立财产，不会和婚后财产混同。再婚不是不信任对方，而是给双方都吃一颗定心丸。"

## 二、家企债务隔离场景

### 案例3：王先生——企业主家企隔离（300万现金+3000万保单家族信托）

**【客户背景】** 王先生50岁，制造业企业创始人，企业年营收约2亿元，计划新建生产线并推动上市，总投资约6000万元，拟向银行贷款3000万元，银行要求控股股东及其配偶承担个人无限连带责任担保。

**【核心诉求】**
1. 太太明确表示"不愿意搭上全部身家去扩大规模"
2. 无论企业经营如何，家人生活品质不受影响
3. 三个子女的国际学校教育、日常生活开销、养老保障都要有底线

**【方案设计】** "300万现金+3000万保单"家族信托架构：
- 现金300万作为信托初始资金，用于缴纳保单保费及日常运作
- 保单部分：总保额3000万元定额终身寿险，120万元×10年缴费
- 受益人：王太太和三个子女
- **分配方案**：三个子女每人从18周岁起每年领取30万元生活金直至30岁；考取本科/硕士/博士分别领取20万元教育金；王太太在委托人去世后每季度领取6万元生活金；重大疾病凭发票报销；紧急备用金每次50万元

**【三重保护机制】**
1. **家企隔离**：装入信托的300万现金和3000万保单现金价值，在法律上已与王先生个人财产分离
2. **杠杆放大**：每年120万保费投入，换取3000万身故保障（杠杆25倍）
3. **定向滴灌**：按年、按条件逐步释放资金，避免一次性给付导致的挥霍

**【顾问话术参考】** "签担保是为企业负责，做信托是为家人负责——两者不矛盾，而且后者更重要。银行那边的担保您照签，但家里的底线已经守住了。"

### 案例4：张先生——债权家族信托（规范家企混同）

**【客户背景】** 企业家张先生，公司早期存在"公私混同"问题，夫妻档公司被视为实质一人公司，金税四期上线后希望规范税务合规。

**【方案设计】** "债权家族信托+股权信托+保险"综合架构：
1. 将个人对企业的存量债权及部分现金、保单交付设立家族信托，家族信托成为企业"合法债权人"
2. 部分优质家族企业资产分拆，设立股权家族信托，通过"家族信托+有限合伙"双层架构实现所有权集中管理
3. 债权利息回流信托后，用于缴纳张先生夫妻、女儿、女婿的养老年金保险

**【五大功能效果】**
1. **家企防火墙**：信托成为借贷主体，债权与个人资产隔离
2. **财务规范化**：企业报表从"其他应付款-股东借款"变为"金融机构借款"
3. **税务优化**：信托公司可开具利息增值税发票，企业可税前扣除
4. **隐私保护**：债权信息不对外公开
5. **传承衔接**：债权本息回流后通过保险实现全家养老保障

## 三、财富精准传承场景

### 案例5：S总——多子女差异化传承（A/B/C类受益人+保密条款）

**【客户背景】** S总退休企业高管，育有三个儿子。长子事业有成独立性强；次子事业稳定家庭美满；小儿子28岁无业未婚，是S总最为放心不下的。

**【核心诉求】**
1. 对三个儿子及孙子女做出差异化安排
2. 特别为小儿子的未来提供更周全的经济保障
3. 同时对孙子辈表达特别的关爱
4. 分配不均的信息不能外露，避免兄弟猜忌

**【方案设计】** 家族信托，受益人分为A/B/C三类：
- **A类（长子及后代）**：信托利益29%，侧重教育金和婚嫁金激励性给付
- **B类（次子及后代）**：信托利益19%，同A类标准
- **C类（小儿子及后代）**：各归属10%+预留"未来直系血亲"，基本生活金高于A/B类，附加"参加工作满一年"等前置条件
- **保密条款**：所有受益人仅知道自己的分配内容，互不知晓他人份额

**【激励性条件设计】** 基础保障层+行为激励层双层结构。小儿子生活金虽高但设置"参加工作满一年"解锁条件；创业启动金需提交商业计划书；连续工作三年且收入达标后额外发放创业启动金。

### 案例6：L女士——上市公司股票传承（2亿股票+一致行动人安排）

**【客户背景】** L女士资深企业家，与女儿、女婿共同控制一家估值100亿元的上市公司，年事已高，希望将股份定向传承给大女儿和外甥女及其后代，同时保持控制权稳定。

**【方案设计】** "上市公司股票信托+一致行动人安排"双层架构：
- L女士以约2亿元初始资金设立家族信托
- 家族信托作为LP（有限合伙人）向有限合伙企业注资
- L女士100%持股的公司作为GP（普通合伙人）
- 有限合伙企业持有上市公司股票
- GP公司在章程中明确控制权保障机制+一致行动人协议

**【核心价值】** "所有权、经营权、受益权"三权分立：
- 家族信托（LP）享有分红等经济收益
- GP公司掌握企业实际经营管理权
- 大女儿作为信托受益人享受分配，但个人债务、婚姻风险不会传导到企业股权

## 四、二代接班与股权传承场景

### 案例7：杉杉股份模拟方案——假设郑永刚提前设立信托

**【实际悲剧】** 郑永刚持股宁波青刚51%间接控制杉杉股份，2023年突发心脏病离世，未留遗嘱。股权经夫妻共同财产析产和法定继承两轮分割——51%股权中约25.5%归遗孀周婷，剩余由五位继承人均分，接班人郑驹仅获约5.1%。此后家族内斗近三年，2025年杉杉集团进入破产重整，郑氏家族彻底出局。

**【模拟方案】** 假设2018年设立股权家族信托：
- 郑永刚为委托人，以现金设立家族信托
- 家族信托作为LP向有限合伙企业注资
- 郑永刚100%控股的公司担任GP
- 有限合伙企业持股宁波青刚51%，间接控制杉杉股份
- 受益人包括郑驹和周婷及其子女
- GP公司股权继承提前在章程中安排——郑永刚身故后由郑驹自动接棒

**【方案优势】**
1. 股权不分割——51%股权永远在信托架构内
2. 控制权稳定——郑驹通过接任GP自动接掌经营权
3. 受益平衡——周婷和子女们作为受益人共享分红
4. 经营连续——控制权平稳过渡
5. 家族永续——信托架构可跨代持续

**【顾问话术参考】** "51%的股权看起来很多，但经过析产和法定继承两刀切下去，接班人就只剩1/5了。信托把股份'锁'在法律架构里，谁来经营企业由您生前定好的规则说了算，每个家人都能受益，股权不会被分散。"

## 五、养老规划与隔代关爱场景

### 案例8：高女士——丁克家庭养老信托（"信托+康养+公益"三位一体）

**【客户背景】** 高女士65岁，退休企业集团高管，与丈夫感情和睦但无子女。

**【三大结构性难题】**
1. 决策人缺失——逐渐失能失智时谁来做出重大决策
2. 财产被侵占风险——没有直系后代监督
3. 服务对接难——缺乏专业机构对接高品质养老资源

**【方案设计】** 500万年金保险+500万现金，总规模1000万元家族信托：
- **养老服务机构直付**：信托财产定期直接向养老社区支付入住费、护理费和医疗费
- **亲属感谢金**：指定亲属在她去世后每人可领取20万元
- **公益捐赠**：剩余款项在她去世后一次性捐赠至指定公益基金会
- **双保护人架构**：爷爷→孙子本人（顺位接替）

### 案例9：李女士——隔代关爱信托（300万现金+700万保单给孙子）

**【客户背景】** 李女士69岁，退休国企高管，与13岁孙子感情极深，希望把财富全部定向传承给孙子。

**【方案设计】** 300万现金+700万保单（年金险，3年期缴），总规模1000万元，受益人仅有孙子一人：
- 参加工作之日起每半年领取9万元
- 结婚之日起每半年领取12万元
- 第一个孩子出生之日起每半年领取18万元
- 第二个孩子出生之日起每半年领取24万元
- 医疗金每年2次凭发票报销
- 紧急备用金35岁起可申请，累计上限100万元
- **双保护人架构**：第一任保护人爷爷，第二任保护人孙子本人（未满18岁由父亲代行）

**【设计精髓】** 递进式分配——金额随人生阶段递增（9万→12万→18万→24万/半年），匹配人生责任逐步加重。以人生事件为触发条件而非简单按年龄发放，传递"先立业、再成家、再育儿"的价值观。

**【顾问话术参考】** "李阿姨，您对孙子的这份心，真是隔代亲的最好写照。直接给孙子一笔钱，怕他太小乱花，也怕儿子儿媳代为管理不尽心。信托可以让您把这份爱变成'分期付款'——不是一次性给完，而是在孙子参加工作、结婚、生子这些重要时刻，每半年都有一笔来自奶奶的钱到账。就算您百年以后，孙子每次收到钱都会想起您。"

## 六、综合案例

### 案例10：陈女士——3000万家族信托（标准架构+保护人+投资管理）

**【家庭背景】** 陈女士58岁，与丈夫共同经营医疗器械企业近三十年，企业年营收过亿元，家庭可投资资产约8000万元。育有一子一女，儿子32岁已婚育有一女，女儿28岁未婚。

**【核心关切】**
1. 儿子婚后若婚姻生变，家产被分割
2. 孙女刚满3岁，希望留一份"跨越时空的爱"
3. 丈夫身体欠佳，担心自己年事已高后管理力不从心
4. 希望将部分家庭资产与企业风险彻底隔离

**【方案设计】** 3000万元现金设立鸿图系列（定制型）家族信托：
- **架构**：标准三权分离+双保护人（第一任丈夫→第二任儿子→女儿顺位接替）
- **差异化分配**：
  - 陈女士和丈夫：每季度20万元养老生活金
  - 儿子：每半年15万元，明确约定为**个人财产**
  - 女儿：每半年12万元
  - 孙女：18岁起每半年10万元教育金，结婚30万元婚嫁金，生育20万元生育金
  - 所有受益人65岁后生活金自动上调50%
- **投资管理**：R3平衡型策略（货币8%+纯债25%+固收+40%+多策略15%+权益12%），组合年化收益6.92%（2018-2025年实测）

**【案例启示】** 保护人制度确保始终有人"掌舵"，专业投资确保这笔钱"不缩水"，差异化分配确保每个家人都能感受到心意。
