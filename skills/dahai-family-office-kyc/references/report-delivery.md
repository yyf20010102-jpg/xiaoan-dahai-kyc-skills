# 大海高客 KYC 报告交付规范

## 格式选择

- 三阶段分析完成且用户确认事实与判断后再生成报告。
- 用户未指定格式时，默认使用 `$pdf:pdf` 生成客户版PDF。
- 用户明确要求演示稿、PPT或可编辑PPTX时，使用 `$ppt-master` 生成，不自行改用HTML演示工具。
- PDF与PPTX只负责呈现，不得改变资产门槛、产品数据、决策树、话术和免责声明。

## 默认10页内容结构

| 页 | 页面任务 | 必须包含 |
|---|---|---|
| 1 | 封面 | 客户称呼或代号、报告日期、顾问/团队；不展示完整敏感身份信息 |
| 2 | 执行摘要 | 客户层级、3至5条核心判断、当前优先动作、信息完整度 |
| 3 | 人：家庭与关键角色 | 家庭成员、责任关系、决策人和影响人，区分事实/推断/待确认 |
| 4 | 财：资产与现金流 | 资产结构、企业与家庭边界、负债、流动性、已有保障 |
| 5 | 情事：关系与关键事件 | 婚姻、企业、传承、养老、子女或债务场景与时间窗口 |
| 6 | 风险与缺口 | 五大场景匹配、风险优先级、保障缺口及计算依据 |
| 7 | 保险底座 | 保障目标、险种分工、预算边界、核保与实施顺序 |
| 8 | 信托/家办可选路径 | 适用条件、保险金信托/家族信托/暂不配置的多选项对比 |
| 9 | 决策与行动路线 | 分阶段行动、所需材料、陪访分工、关键异议与下一次触达 |
| 10 | 依据与免责声明 | 数据来源、产品参数来源、待确认清单、风险提示和免责声明 |

信息较少时可合并为8至9页，最终不得超过10页。客户不满足信托条件时，第8页改为“保险与现金流优化选项”，不得强行保留信托内容。

## 数字、合规与隐私

- 所有关键判断标注“明确事实”“合理推断”或“待确认”。
- 默认隐藏身份证号、手机号、详细住址、账户号码、企业机密和病历原文；对外版优先使用代号。
- 费率、保费、收益、保额杠杆和产品参数只使用官方资料、技能内已验证资料或代理人确认值。
- 找不到可靠数据时写“待确认”，禁止估算或制造虚假精度。
- 保险与信托以多选项对比呈现，写清准入条件、限制和决策依据，不承诺收益、承保结果或确定法律效果。

## 生成与校验

### PDF

1. 使用 `$pdf:pdf` 创建和验证最终PDF；可复用 `scripts/kyc_pdf_generator.py` 进行数据转换。
2. 把确认后的“人财情事”、场景判断、缺口测算、配置选项和行动计划填入上述结构。
3. 渲染全部页面检查中文字体、表格分页、图表、页码、数据来源和免责声明。
4. 发现问题时修复源数据或生成脚本后重新生成，不直接修改最终PDF掩盖问题。

### PPTX

1. 使用 `$ppt-master`，严格遵循其路由和确认节点。
2. 默认生成10页，允许压缩至8页；保持全部文字和图表可编辑。
3. 图表只使用已确认数据，信托选项不能因视觉需要被夸大。
4. 完成后检查页数、首尾页、模板残留、文本溢出、数据来源和可编辑性。
