# 2026挪储场景话术库

> 基于平安人寿总部产品设计部副总经理**王瑞**关于「变化时代中的平安新解法」观点，结合2026年大规模存款到期潮的行业背景编制。
>
> **王瑞核心观点**：经济周期变化叠加老龄化，资产配置、医疗健康、养老规划愈发重要。平安视角下，应对复杂环境需要综合解决方案。

## 一、挪储背景数据（代理人知识武装）

### 1.1 2026年存款到期潮核心数据

| 数据指标 | 具体数字 | 来源 |
|:---|:---|:---|
| 居民定期存款到期规模 | 约50万亿~75万亿元 | 华泰/国信/中金测算 |
| 到期规模同比增加 | 较2025年多增约4-10万亿元 | 多家券商共识 |
| 三年期定存利率变化 | 从此前3.1%降至**1.55%**（国有大行） | 央行利率调整 |
| 五年期大额存单 | 大面积下架，几乎绝迹 | 各银行公告 |
| 三年期大额存单利率 | 普遍降至"1"字头（1.1%-1.9%） | 银行网点调查 |
| 市场比喻 | **"笼中虎出笼"**——大量高息存款到期后需重新定价 | 学界+市场共识 |
| 资金主要流向 | 保险、理财产品、货币基金等低风险资产 | 银行渠道调研 |
| 主力保险产品 | **分红型增额寿险、年金险** | 险企营销定位 |
| 央行政策信号 | "2026年仍存在降准降息空间"（邹澜副行长） | 2026年1月央行发布会 |

### 1.2 客户痛点三角（挪储三大焦虑）

```
        收益缩水焦虑
        （3.1% → 1.5%）
           /    \
          /      \
  流动性错配    锁定利率窗口关闭
（怕锁太久）    （利率可能继续降）
```

### 1.3 代理人一句话总结（背下来）

## 二、小安版挪储话术（普客/新人适用）

### 2.1 KYC采集时的自然提问（引出挪储话题）

**话术1：从存款习惯入手**
> "您平时闲钱一般放哪儿？银行定期还是理财？最近存单到期续的时候有没有发现利率比之前低了不少？"

**话术2：从焦虑切入**
> "最近好多客户跟我反映，之前存的三年期到期了，续存发现利率都快腰斩了。您有遇到这种情况吗？"

**话术3：从新闻闲聊**
> "最近央行放出风声说今年还有降息空间，朋友圈都被'50万亿存款搬家'刷屏了。您平时关注这些财经消息吗？"

**话术4：从家庭财务规划引入**
> "咱们聊保障之前，先看看您家现在的钱都放哪了——银行定期、理财、基金大概各占多少？有没有最近到期的大额存单？"

### 2.2 痛点唤醒话术（让客户意识到问题）

**话术1：算账法（最有杀伤力）**
> "咱们简单算一笔账：如果您有50万存三年定期，之前利率3.1%，三年利息是**46,500元**。现在利率1.5%，三年利息只有**22,500元**。同样一笔钱放三年，**少拿24,000元**。这不是小数目，够孩子一年兴趣班了。"

**话术2：对比法**
> "隔壁银行三年期大额存单利率已经降到1.55%了，而且5年期的基本都下架了。越往后可能越低——央行副行长都公开说了'还有降息空间'。您现在不锁定，以后可能连1.5%都拿不到。"

**话术3：类比法**
> "存定期就像坐慢车——以前速度还行，现在越开越慢，而且票价还在涨（通胀）。保险产品相当于给您换一张'固定速度的高铁票'——不管外面利率怎么降，您这份保单的现金价值是写进合同的。"

**话术4：引用王瑞观点**
> "平安总部产品设计部的王瑞总说了，经济周期变化叠加老龄化，每个人都要面对资产配置和养老规划的问题。咱们现在聊的，就是帮您用保险这个工具，把利率下行周期里最珍贵的'确定性'锁住。"

### 2.3 产品对接话术（方案→产品）

**增额终身寿险定位——"大额存单平替"**
> "您到期的存款大概率要重新找地方放。银行现在推得最多的就是增额终身寿险——它像一个'升级版大额存单'：保底收益写进合同（目前约1.75%），加上浮动分红，演示收益率在2.5%以上。比存银行高，而且锁定的是终身利率，不受以后降息影响。"

**年金险定位——"强制储蓄+终身现金流"**
> "如果您这笔钱是打算以后养老用的，年金险更合适——就像给自己发工资，到时候每月准时到账，活多久领多久。社保只能保证饿不死，商业年金险保证活得有尊严。"

**小额定投切入——"每月少喝几杯咖啡"**
> "不用一次拿很多钱。每月1000-2000块起，相当于少下几次馆子，就能给自己攒一份确定性的养老金。关键是越早开始，复利滚得越大。"

### 2.4 常见异议处理

**异议1："我还是觉得存银行方便，随取随用"**
> "确实方便。但咱们换个角度想——正因为太方便了，钱才容易花掉。您回忆一下，这几年定期到期后有多少是真正续存的？是不是总有各种理由拿出来花了一部分？保险的好处就是'不方便'——强制您存下来，将来回头看会感谢现在的自己。而且急用钱的话，保单可以贷款，一般能贷出现金价值的80%，利息也不高。"

**异议2："利率还会涨回来的吧？"**
> "央行副行长1月份公开说了——2026年还有降准降息空间。利率往下走的趋势短期内很难反转，看看日本和欧洲就知道了，负利率都搞了多少年。咱们别赌利率涨，先把现在的利率锁定住才是实在的。"

**异议3："分红是不确定的，万一不分呢？"**
> "说得很对，分红确实不是保证的。但增额终身寿险的好处是有**保底**——现金价值写进合同，不管分不分红，这部分是确定的。分红相当于'额外惊喜'。而且平安的投资能力大家有目共睹，这么多年分红实现率都在行业前列。"

**异议4："我不太懂保险，怕买错"**
> "完全理解。咱们今天不是在推销产品，而是帮您看清楚——您的钱现在放银行利率越来越低，将来要用的教育金、养老金早晚得有个地方放。保险不是唯一的答案，但可能是最适合中长期资金配置的工具。您先了解，觉得合适再决定。"

## 三、大海版挪储话术（高客适用）

### 3.1 高客挪储的核心差异

普客关注的是"利率降了多少、少拿多少利息"，高客关注的是"资产如何穿越周期、钱放在哪里最安全"。

| 维度 | 普客视角 | 高客视角 |
|:---|:---|:---|
| 关注点 | 利率差额、少赚了多少钱 | 资产配置效率、风险隔离、确定性 |
| 痛点 | 到期利息变少 | 大量现金在低效"休眠" |
| 方案 | 增额寿/年金险单独购买 | 保险+信托组合、资产再配置 |
| 话术基调 | 算账、对比、锁定利率 | 资产架构、穿越周期、法税合规 |

### 3.2 KYC采集时引出挪储话题（高客版）

**话术1：从资产配置切入**
> "王总，您现在的资产分布大概是怎样的？现金、定存、理财、股权各占多少？最近有没有大额定存到期需要重新规划的？"

**话术2：从宏观趋势引入**
> "央行已经放风今年还有降息空间，50万亿存款到期潮来了。很多企业主客户最近都在讨论这件事——大笔现金原来放定存拿3个点，现在只能拿1个点出头，钱在'睡觉'。您是做企业的，肯定比我更敏感。您这边有这方面的考虑吗？"

**话术3：引用王瑞观点建立专业感**
> "最近我们总部产品设计部的王瑞总在一个专访里提到，经济周期变化叠加老龄化，资产配置和养老规划比以往任何时候都重要。特别是在当前存款利率持续走低的大环境下，怎么让资产'保值'比'增值'更考验智慧。您觉得呢？"

### 3.3 高客痛点唤醒话术

**话术1：资产"含金量缩水"法**
> "假设您有500万放在三年期定存。之前3%的时候，每年利息15万，够请一个好司机。现在降到1.5%，每年利息7.5万，差了整整一半。关键是这还只是开始——如果央行继续降息，明年可能就是1.2%、后年1%。您这500万的实际购买力在持续缩水。这不是小账，是企业经营之外需要重点关注的家庭资产保值问题。"

**话术2：确定性稀缺法**
> "现在市场上不缺投资机会，缺的是'确定性'。股票涨跌不定，理财打破刚兑，信托也有暴雷。但您的家庭需要一笔确定性的钱——孩子教育、自己养老、万一企业出问题后的生活保障。保险公司给的就是这份确定性，写进合同、法律保护。这是任何理财产品都给不了的东西。"

**话术3：时间窗口法**
> "利率下行是大趋势。日本零利率搞了二十多年，欧洲负利率也不是新鲜事。现在趁国内还有2%以上的锁定利率产品，赶紧把一部分资产从'浮动利率'切换到'固定利率'。等利率降到1%以下再想锁定，就晚了。这个窗口期不会太长。"

**话术4：家族财富架构法**
> "高净值客户的资产配置，不是简单的'买什么产品'的问题，而是'搭什么架构'的问题。保险+信托的组合，相当于给家族财富装了一个'中央空调系统'——不是随天气（利率）忽冷忽热，而是恒温恒湿。到期的定存，正是重新搭建这个架构的最好契机。"

### 3.4 高客产品对接话术

**增额终身寿险——"确定性压舱石"**
> "咱们把到期的定存分成两块：一块作为家庭的'压舱石'，通过增额终身寿锁定终身利率，不管将来利率降到多少，您这块资产按合同约定稳健增值。另一块保持流动性，继续放在银行理财或短期产品里。这样既有进攻又有防守。"

**保险金信托——"让钱有规矩地流动"**
> "您这笔到期存款放进保险后，身故理赔金可以对接保险金信托。这样不是一次性把钱打给家人，而是按您定的规矩分期给——比如受益人每月领多少、孩子考上大学额外给多少、结婚时给一笔贺礼。钱不再是'泼出去的水'，而是'有开关的水龙头'。"

**家族信托——"从定存到架构"**
> "定存到期其实是一个重新审视家族财富架构的好时机。以前利率高的时候，放着吃利息没问题。但现在利率降到这个程度，继续放定存等于财富在贬值。不如趁这个机会，用保险+家族信托搭一个完整的财富管理架构——底层资产锁利增值、中间层信托隔离保护、上层按您的意愿精准分配。"

### 3.5 高客常见挪储异议

**异议1："我这里利率还行，不急"**
> "理解，您可能对接的是私人银行或大额协议存款，利率确实比普通客户高。但有两个问题值得关注：一是协议存款到期后能不能续约、续约利率能不能保证？二是即使您现在能拿到比别人高的利率，整体趋势还是往下走的。现在锁定，相当于用今天的利率锁住未来的收益。"

**异议2："我企业需要现金流，不能锁太久"**
> "我们不是把所有钱都锁进去。企业需要的流动资金留在银行或短期理财，该周转的照常周转。咱们今天讨论的是那部分'暂时用不上的钱'——比如您本来放三年定存的那部分，三年内您本来也不会动它，为什么不放到一个收益更高、还有保障功能的地方呢？而且保单贷款非常方便，真有急用随时能贷出来。"

**异议3："信托太复杂，我怕麻烦"**
> "其实不复杂。保险金信托最快2小时就能设立——您只需要把自己已有的保单受益人改成信托公司就行。家族信托复杂一点，但我们有专门的团队全程协助。您要做的事情很少，大部分我们帮您办好。就像装修房子，您只需要说'我要什么风格'，施工队帮您搞定。"

## 四、挪储场景的触达策略

### 4.1 哪些客户适合用挪储话术切入

| 客户特征 | 触达优先级 | 切入话术 |
|:---|:---|:---|
| 40-60岁，有50万+定期存款 | ⭐⭐⭐⭐⭐ | "存款到期潮"算账法 |
| 企业主，有大额闲置资金 | ⭐⭐⭐⭐⭐ | "资产配置架构"法 |
| 退休/临近退休，依赖利息收入 | ⭐⭐⭐⭐⭐ | "锁定终身现金流"法 |
| 30-40岁，有定期存款习惯 | ⭐⭐⭐⭐ | "每月少喝咖啡"小额定投法 |
| 刚卖房、有卖房款在手 | ⭐⭐⭐⭐⭐ | "卖房款再配置"法 |
| 对财经新闻敏感、关注利率 | ⭐⭐⭐⭐⭐ | "宏观趋势+行业数据"法 |

### 4.2 触达节奏建议

```
第一步：引发关注（微信/电话）
  → 分享"50万亿存款到期""利率腰斩"等新闻，不推销产品
  → 话术："最近看到央行说还有降息空间，朋友圈都在讨论存款搬家。您有注意这事吗？"

第二步：算账唤醒（面访/电话）
  → 帮客户算一笔账：到期续存少拿多少钱
  → 话术：用"算账法"让客户感知到具体损失

第三步：方案对接（面访）
  → 展示保险产品的确定性优势
  → 话术：用"大额存单平替"（普客）/ "确定性压舱石"（高客）

第四步：行动促单
  → 强调利率下行窗口期
  → 话术："央行放风还要降息，趁现在还能锁定X%……"
```
