# 平安人寿KYC分析工具skill 实战评估报告

**评估人视角**：平安人寿上海分公司从业15年+资深保险代理人，带过50+人团队
**评估对象**：kyc-analyzer-v3/SKILL.md
**评估日期**：2025年

---

## 一、总体评分：4/10

这个工具有一个**看起来不错的理论框架**（三阶段流程：KYC采集→需求分析→方案设计），底层引用了《客户宝典》这本高质量的教材，**但在真实展业场景中几乎是不可用的**。

它犯了保险新人最容易犯的错误——**把面访当成填表，把客户当成数据**。15年带团队的经验告诉我，一个工具好不好用，不看它输出的报告多漂亮，而看它能不能帮代理人在真实场景中**自然、顺畅地拿到结果**。这个工具在"自然"和"顺畅"两个维度上都严重不合格。

---

## 二、五大维度详细评估

### 2.1 面访前准备（评分：3/10）

#### 缺失的关键模块

| 缺失项 | 严重程度 | 说明 |
|--------|---------|------|
| 面访目标设定 | 严重 | 工具没有区分：首次面访（破冰+KYC）vs 二访（方案呈现）vs 促成交面访。不同面访的KYC重点完全不同 |
| 客户来源标签 | 严重 | 转介绍客户、缘故客户、网络客户、活动客户的面访策略差异巨大，工具完全未区分 |
| 信息预收集 | 中度 | 代理人见客户前通常已从转介绍人或朋友圈获取了部分信息，工具没有"已知情信息"的填入入口 |
| 面访场景预判 | 中度 | 没有帮助代理人预判：客户可能的抗拒点、可切入的话题、时间限制等 |
| 破冰话题库 | 严重 | 上海客户第一次见面需要自然破冰，工具没有提供任何破冰素材 |
| 面访时长规划 | 中度 | 没有根据不同客户类型和面访阶段规划时长，20题在真实面访中根本无法完整执行 |

#### 现有内容的致命缺陷

15-20题的问题设计**逻辑顺序死板**，所有客户都走同一套流程。真实展业中：
- 高净值客户第一次见面不会接受被"审问"20个问题
- 年轻客户可能对保险话题本身就有抗拒
- 中年客户最关心的是子女教育和养老，应该从他们关心的话题切入

**建议：按客户类型和面访目标提供差异化的问题模板。**

### 2.2 面访中引导（评分：2/10）——**最大的败笔**

这是整个工具最致命的部分。作为一个带过上百场陪访的团队长，我可以负责任地说：**按照SKILL.md的方式在面访中采集KYC，80%的客户会在第5题之前找理由结束对话。**

#### 具体问题的实战分析

| 题号 | 问题原文 | 实战问题 | 严重程度 |
|------|---------|---------|---------|
| 2 | "客户今年多大年纪？" | 第一次见面就问年龄，女性客户尤其反感。需要包装为"您是几几年的？看起来挺年轻" | 中 |
| 4 | "客户是做什么工作的？具体职位是什么？" | 上海金融圈很多人对自己收入讳莫如深，直接问会触发防御 | 中 |
| 5 | "结婚了吗？有孩子吗？孩子多大了？" | 合理，但需要自然的过渡，不能一个接一个机械地问 | 低 |
| 8 | **"家里主要靠谁赚钱？如果客户不工作，家里能维持多久？"** | **这是核心隐私！** 在江浙沪文化中，这种问法被认为是极度冒犯。不是不信任你，而是面访还没到这个信任层级 | **极严重** |
| 10 | **"客户大概年收入在什么水平？"** | 中国客户的收入是最高频的抗拒点。没有铺垫直接问，90%的客户会给一个模糊数字或明显偏低的数字 | **极严重** |
| 11 | **"有房贷吗？还剩多少没还？月供多少？"** | 负债信息比收入更敏感。问"还剩多少没还"等于问"你欠了多少钱"，客户会抵触 | **极严重** |
| 13 | "每月固定支出大概多少？能存下多少钱？" | 支出信息客户自己也算不清楚，得到的回答没有参考价值 | 中 |
| 15 | **"最近体检了吗？有什么异常指标吗？比如结节、脂肪肝、三高？"** | **列举异常指标等于在暗示客户不要告诉你**。而且健康隐私是信任度极高的信息，刚认识根本问不出来 | **极严重** |
| 17 | "如果突然生病住院，第一个电话会打给谁？" | 意图是好的（了解支持网络），但问题本身突兀、煽情，上海客户会觉得"莫名其妙" | 中 |
| 20 | "买保险这件事，客户自己能做主吗？" | 决策模式的信息需要在面访过程中自然观察，不能这样直接问 | 中 |

#### 深层问题

**1. 面访不是审讯，而是聊天**
真实面访中，KYC信息的获取是**穿插在自然对话中**的，不是"第1题→第2题→第3题"这种机械流程。SKILL.md的设计完全违背了这条铁律。

**2. 问题之间没有过渡话术**
从"结婚了吗"跳到"父母还在吗"再跳到"年收入多少"，面访变成了冷冰冰的信息采集。真实面访中每个问题之间需要**情感连接和话题过渡**。

**3. 没有"追问"和"应对抗拒"的话术**
客户说"大概就这样吧"怎么追问？客户说"这个不方便说"怎么化解？客户说"保险都是骗人的"怎么接？工具完全没有这些实战中最需要的应对策略。

**4. 没有面访节奏控制**
真实面访中，代理人要感知客户的情绪状态：客户开始看手机了→要收；客户聊high了→要多采一些；客户皱眉了→要换个话题。工具完全没有节奏感知和调整机制。

### 2.3 面访后复盘（评分：5/10）

这是三个模块中相对最好的，但仍有不少问题。

#### 做得好的地方
- 风险诊断的三级体系（高危/中度/潜在）比较实用，可以直接用于和客户的二次沟通
- 客户类型识别和生命周期定位的框架合理
- 引用《客户宝典》的反常识洞察有专业度

#### 严重问题

| 问题 | 严重程度 | 说明 |
|------|---------|------|
| 输出过于冗长 | 严重 | 完整方案模板包含10+个模块，动辄几千字，代理人在展业间隙根本没有时间消化 |
| 缺少"下一步行动" | 严重 | 面访结束后，代理人最需要知道的是：**今天下午我该做什么？明天我该做什么？** 工具没有明确的行动指引 |
| 缺少客户版本方案 | 中度 | 方案输出只有"代理人版"，没有"客户版"。实际展业需要一份简洁有力的客户展示材料 |
| 预估成交不靠谱 | 中度 | "成交概率：高/中/低"和"预计首年保费"这种粗糙估算没有实战价值 |
| 跟进计划太笼统 | 中度 | "按时间节点跟进"说了等于没说，需要的是具体的"本周三下午3点打电话问客户对方案的意见" |

### 2.4 上海本地化（评分：2/10）

作为在上海做了15年的团队长，这个工具的**本地化严重不足**，几乎是"放之四海皆不准"。

#### 上海市场的特殊性完全被忽略

| 上海特殊性 | 工具现状 | 影响 |
|-----------|---------|------|
| **高净值客户**（陆家嘴金融圈、企业家、外籍人士） | 只有笼统的"高净值家庭"一类 | 金融从业者对保险认知很成熟，反感被"审问"，需要资产配置视角而非产品推销视角 |
| **科技新中产**（张江/漕河泾） | 归类为"年轻家庭" | 互联网从业者收入高、工作忙、喜欢用数据说话，需要效率导向的面访方式 |
| **新上海人/外来务工** | 没有单独类型 | 积分落户、学区房、留沪置业是其核心焦虑，需要差异化KYC |
| **沪籍退休人群** | 归类为"退休前人群" | 上海退休老人有大量积蓄，关心养老社区和高端医疗，需要品质导向的沟通 |
| **外籍/港澳台人士** | 完全没有 | 上海有大量外籍人士，需要考虑跨境资产配置、税务、汇率等 |

#### 上海客户的沟通风格未被考虑

- **上海人精明务实**：不喜欢"套路"，反感过度热情，更看重专业度
- **注重隐私**：直接问收入和负债是大忌
- **决策理性**：喜欢用数据说话，但更看重"性价比"而非"收益率"
- **圈层感强**：转介绍在上海极其重要，但工具完全没有转介绍模块

#### 上海特有的保险需求未被覆盖

- **沪惠保+商业医疗险的组合策略**：上海有"沪惠保"这个城市级普惠保险，KYC中完全没有涉及
- **学区房与子女教育**：上海的学区制度极其复杂，是影响家庭财务的核心变量
- **积分与落户**：直接影响购房资格和子女教育，是新上海人最核心的焦虑
- **养老社区**：上海的高端养老社区需求旺盛，但工具只在方案设计中泛泛提及

### 2.5 实际痛点覆盖（评分：2/10）

这是代理人最关心也最失望的部分。

#### 成交辅助 ❌ 严重不足

工具提供了：
- 一个"成交概率"的粗略判断（高/中/低）
- "预计首年保费"的简单估算

**缺失**：
- 促成交的具体话术（什么时候说"这个方案今天下单有优惠"？）
- 促成交的时机判断（客户什么微表情/什么话语代表可以促了？）
- 促成交的策略选择（二择一法、限时法、对比法、故事法……）
- 客户犹豫时的临门一脚话术

#### 异议处理 ❌ 几乎空白

方案模板中有一个"异议处理"的空壳字段，但没有任何实质内容。

**上海客户最常见的异议，工具完全没有覆盖**：

| 异议类型 | 具体话术 | 出现频率 |
|---------|---------|---------|
| 价格类 | "太贵了""我再考虑考虑""我对比一下" | 极高 |
| 信任类 | "我自己就是金融圈的""我有朋友做保险的""平安的产品不如XX公司" | 高 |
| 拖延类 | "等孩子大点再说""等年终奖发了再说""我现在手头紧" | 极高 |
| 产品类 | "这个收益率不如我买基金""返还型的不是更好吗""我买消费型不是亏了" | 高 |
| 决策类 | "我要跟我老公商量""我回去查一下""这个条款我不太理解" | 高 |

**一个KYC工具如果不覆盖异议处理，它的价值大打折扣**——因为KYC的最终目的就是为了处理异议、促成成交。

#### 转介绍 ❌ 完全没有

这是我最不能接受的缺失。在上海这样的市场，**转介绍是优质客户来源的生命线**。一个KYC工具完全不涉及转介绍：
- 什么时候提出转介绍请求？
- 用什么话术？
- 如何降低客户的"卖人情"心理负担？
- 转介绍名单的质量如何评估？
- 如何感谢转介绍人？

#### 客户经营 ⚠️ 部分覆盖

- 有"长期跟进计划"的框架，但太笼统
- 没有客户分级（A/B/C类）的概念
- 没有不同频次的联络计划
- 没有客户"生日/纪念日/保单周年"等关键触点的提醒

## 四、具体改进建议（可落地的）

### 4.1 重构KYC采集方式（优先级：最高）

**核心思路：从"审讯式问答"改为"自然对话引导"**

**建议A：按客户类型提供差异化的问题组合**

| 客户类型 | 建议的问题数量 | 核心切入话题 | 敏感问题处理方式 |
|---------|--------------|------------|----------------|
| 首访/陌生客户 | 5-8个 | 从对方熟悉的话题切入（行业、子女、住房） | 收入/负债问题用间接方式："您对这个预算范围感觉怎么样？" |
| 二访/转介绍 | 10-12个 | 从转介绍人的故事切入 | 已建立初步信任，可以逐步深入 |
| 高净值客户 | 开放式对话 | 资产配置视角，聊宏观、聊家族 | 不提"买保险"，聊"财富管理方案" |
| 老客户加保 | 3-5个 | 从生活变化切入（工作变动、孩子升学、购房计划） | 信任已建立，直接沟通 |

**建议B：每个问题提供"自然话术+追问话术+抗拒化解话术"**

示例（优化后的收入询问）：
```
自然话术："张姐，咱们聊到现在，您对家庭保障这块还是挺上心的。
          一般来说，年收入的10%-15%用来做保障是比较合理的区间，
          您觉得这个预算范围大概在哪个档？"

追问话术："理解理解，确实具体数字不太好说。那大致上，
           是在30万以下、30-50万、还是50万以上这个区间？
           这样我好给您匹配最合适的方案。"

抗拒化解："您放心，这个信息我不会跟任何人说的，只是为了
          帮您算一下保额够不够、保费是否合理。"
```

**建议C：问题之间增加过渡和连接**

每个问题结束时，用一句过渡语自然衔接到下一个话题，而不是机械地"收到，下一题"。

### 4.2 增加异议处理模块（优先级：最高）

建议增加一个完整的异议处理库，至少覆盖8-10个最常见的异议：

```
## 异议处理库

### 异议1："太贵了"
- 底层逻辑：不是真的嫌贵，而是没理解价值
- 应对步骤：1)先认同 2)再算账 3)给选择
- 参考话术："张姐，我完全理解，如果只看这个数字确实不少。
  但咱们换个角度算笔账：您一年在XX上的开销大概XXX，
  而这份保障每年XXX，相当于每个月XXX，
  换来的是万一出事时不拖累家人、不用卖房筹钱。
  您觉得这个账划算吗？"

### 异议2："我再考虑考虑"
- 底层逻辑：要么没信任你，要么没理解方案
- 应对步骤：1)确认顾虑 2)提供新信息 3)设定期限
- 参考话术：...

### 异议3："我有朋友做保险的"
- 底层逻辑：委婉的拒绝
- 应对步骤：...
```

### 4.3 增加转介绍模块（优先级：高）

```
## 转介绍引导（在成交后或客户满意度最高时触发）

### 时机判断
- 最佳时机：客户确认方案并表示认可时
- 次佳时机：客户 thanking you for good service 时
- 避免时机：面访刚开始或客户犹豫时

### 话术模板
- 自然引导式："像您这样有风险意识的朋友，
  周围一定也有不少注重家庭规划的人吧？"
- 价值交换式："如果您觉得今天聊的内容有帮助，
  方便的话也可以推荐给身边有需要的朋友。"
- 圈子切入式："您平时跟哪些朋友走得比较近？
  比如做XX行业的李哥那样的？"

### 降低心理负担
- 强调"专业咨询"而非"推销"
- 提供增值服务作为交换（"我可以帮您朋友免费做一次保单检视"）
```

### 4.4 上海本地化改进（优先级：高）

| 改进项 | 具体内容 |
|--------|---------|
| 增加"沪惠保"相关KYC | "您和家人有没有买沪惠保？对商业医疗险的认知如何？" |

## 五、总结

这个KYC分析工具的**骨架是好的**——三阶段流程逻辑清晰，《客户宝典》的引用有专业深度。但它在**实战层面存在根本性缺陷**：

1. **核心矛盾**：它把面访设计成了"填表"，而真实面访是"聊天"
2. **最大缺失**：异议处理和转介绍这两个代理人最关心的环节几乎空白
3. **本地化差**：在上海这样的多元化市场，工具的适用性大打折扣
4. **输出冗长**：面访后需要" actionable 的行动指引"，而不是一篇论文

如果这个工具能够在以下三个方向上做根本性改进，我会给它打到7-8分：
1. **重构KYC采集方式为自然对话引导**
2. **增加完整的异议处理+转介绍模块**
3. **做上海本地化适配**

否则，它在一线代理人的日常展业中，大概率会被束之高阁。
