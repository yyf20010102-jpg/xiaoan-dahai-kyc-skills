# KYC 保障与长期现金流规划规则

本文件是当前方案设计策略，覆盖 `full-guide.md` 中“医疗险固定400万”“只按收入比例分配保费”等旧默认值。产品名称、费率、现金价值和账户规则必须以当期正式条款、产品说明书和官方利益演示为准。

## 一、规划顺序

按以下顺序判断，不因销售重点变化而跳过前置条件：

1. **流动性底座**：日常支出、应急金、房贷及未来3年内确定支出。
2. **必要保障**：医疗、寿险、意外、重疾按家庭责任和已有保障补缺，不追求名义保额最大化。
3. **长期现金流**：孩子教育、父母赡养、夫妻养老、长期护理等目标明确后，再配置年金、养老和分红型保险。
4. **稳健增值账户**：完成以上资金安排后，长期闲置结余才考虑进入万能账户或其他长期工具。

## 二、家庭结构触发规则

### 有未成年子女

- 同时呈现“子女教育金”和“夫妻养老”两条时间轴，不能只谈孩子、不谈父母自己的退休。
- 当目标期限较长、收入稳定且8年持续缴费不影响应急金和房贷时，提高年金、养老与分红型保险的配置权重。
- 基础保障有明显缺口时，先用较低成本守住家庭责任，再安排长期储备；不得把全部预算锁入储蓄型保单。

### 有赡养老人或客户已进入中老年阶段

- 区分父母当前医疗/护理现金流与客户自己的退休现金流。
- 对退休前客户，提高养老年金、长期护理和稳定领取安排的优先级；对已退休客户优先评估近期流动性、领取时点和退保损失。
- 60岁以上客户必须用易理解方式呈现保证利益、非保证利益、费用和领取限制，并留出充分确认环节。

## 三、医疗险额度规则

- 取消“所有客户统一400万”的默认值。普通家庭默认从**基础档或约100万级保障能力**讨论；真实产品若只有固定额度，写“产品责任限额”，不把它表达成客户必须达到的目标。
- 优先比较续保条件、免赔额、医院范围、外购药/特药责任、既往症与健康告知、团险离职后的连续性，其次才是名义保额。
- 已有社保和团体医疗的客户，先核对团险边界，再决定个人医疗的补充层级。
- 健康异常客户先预核保；不得用提高保额代替核保可行性判断。

## 四、分红险8年缴策略

对符合长期规划条件的客户，可把分红型保险作为教育、养老或长期财富守护工具，默认讨论**8年缴费结构**：

- 先确认产品确实支持8年缴，并取得当期正式条款、产品说明书和官方利益演示。
- 年缴金额以“连续8年可持续”为核心，不直接按年收入比例塞满预算；至少核对应急金、房贷、教育近期开支、收入下降情景和提前退保损失。
- 报告必须分开列示：保证利益/现金价值、非保证红利、领取节点、退保损失和最差情景。
- 分红是非保证利益，不使用“保本保息、稳赚、锁定高收益、确定分红”等表述。

## 五、万能账户安排

“多余钱进入万能账户”必须改写为有前置条件的资金顺序：

1. 留足应急金和未来3年确定支出；
2. 预留当年及后续分红险缴费；
3. 覆盖房贷、必要保障和家庭照护责任；
4. 剩余且长期不用的资金，在合同允许追加时，才考虑进入万能账户。

报告必须披露最低保证利率、实际结算利率的非保证性、初始/追加费用、退保或部分领取费用、领取限制、账户价值变化和合同终止条件。不得把当前结算利率当作未来收益承诺。

## 六、KYC输出要求

每份方案至少包含四个资金桶：

| 资金桶 | 主要任务 | 输出要求 |
|---|---|---|
| 应急与短期 | 日常、应急、3年内支出 | 金额或“待确认”，不可锁定 |
| 保障底线 | 医疗、寿险、意外、重疾 | 说明缺口、已有保障和额度依据 |
| 长期确定现金流 | 教育、养老、护理 | 说明目标年份、领取需求与缴费能力 |
| 稳健增值 | 分红险、万能账户等 | 区分保证与非保证，列费用与流动性风险 |

输出基础/标准/进阶三档时，差异应优先体现在长期储备金额和万能账户追加节奏，而不是单纯堆高医疗保额。

## 七、官方披露依据

- [《人身保险产品信息披露管理办法》](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=1081986)：产品信息披露须真实、准确、完整、及时。
- [《关于健全人身保险产品定价机制的通知》](https://www.nfra.gov.cn/cn/view/pages/governmentDetail.html?docId=1175200&generaltype=1&itemId=861)：分红与万能产品应平衡保证利益和浮动利益，合理引导客户预期。
- [《关于加强万能型人身保险监管有关事项的通知》](https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=1206222&generaltype=1&itemId=4110)：万能账户按真实投资收益结算，结算利率应审慎确定并动态调整。
