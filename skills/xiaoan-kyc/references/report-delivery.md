# 小安 KYC 报告交付规范

## 格式选择

- 三阶段分析完成且用户确认事实与方案后再生成报告。
- 用户未指定格式时，默认使用 `$pdf:pdf` 生成客户版PDF。
- 用户明确要求演示稿、PPT或可编辑PPTX时，使用 `$ppt-master` 生成，不自行改用HTML演示工具。
- PDF与PPTX只负责呈现，不得改变 `xiaoan-kyc` 的业务结论、金额依据和合规判断。

## 默认8页内容结构

| 页 | 页面任务 | 必须包含 |
|---|---|---|
| 1 | 封面 | 客户称呼或代号、报告日期、顾问/团队；不放身份证号、手机号和住址 |
| 2 | 一页结论 | 3至5条核心发现、信息完整度、当前最重要行动 |
| 3 | 客户画像 | 生命周期、职业与收入稳定性、家庭角色、明确事实/推断/待确认 |
| 4 | 家庭与财务结构 | 家庭责任、现金流、负债、已有保障；只展示已确认数字 |
| 5 | 风险与需求优先级 | 刚性事件、处理顺序；有孩子或赡养老人时呈现教育与养老时间轴 |
| 6 | 保障与长期资金边界 | 必要保障、8年缴费能力、应急金和预算边界 |
| 7 | 配置建议 | 基础/标准/进阶选项；适用时呈现分红险8年缴、养老年金和万能账户资金顺序 |
| 8 | 行动计划 | 下一步、材料、跟进节奏、异议处理、合规免责声明 |

内容简单时可压缩为6至7页，复杂时最多10页。增加页面只允许用于“关键异议与沟通策略”或“数据依据/待确认清单”，不得增加纯装饰页。

## 内容与隐私

- 每个关键判断标注“明确事实”“合理推断”或“待确认”。
- 对外版优先使用客户称呼、姓氏或档案代号；默认隐藏身份证号、手机号、详细住址、病历原文和账户号码。
- 健康异常只保留影响核保判断的必要摘要，并注明最终以保险公司核保为准。
- 保额、保费、预算比例和产品参数必须写明依据；无法验证时写“待确认”。
- 医疗险不默认展示400万；普通家庭从基础档或约100万级保障能力讨论，重点解释续保、免赔、医院和药品责任。
- 分红险必须分开保证利益与非保证红利；万能账户必须分开最低保证利率与非保证结算利率，并列出费用和领取限制。
- “分红险8年缴 + 长期结余进入万能账户”仅在现金流可持续、条款允许且客户理解流动性代价时展示。

## 生成与校验

### PDF

1. 使用 `$pdf:pdf` 创建和验证最终PDF；可复用 `scripts/kyc_pdf_generator.py` 进行数据转换。
2. 把确认后的KYC摘要、需求分析、配置建议和行动计划填入上述结构。
3. 渲染全部页面检查中文字体、表格分页、溢出、页码和免责声明。
4. 发现问题时修复源数据或生成脚本后重新生成，不直接修改最终PDF掩盖问题。

### PPTX

1. 使用 `$ppt-master`，严格遵循其路由和确认节点。
2. 默认生成8页，最多10页；保持全部文字和图表可编辑。
3. 图表只使用已确认数据，不为视觉完整补造数字。
4. 完成后检查页数、首尾页、模板残留、文本溢出和可编辑性。
