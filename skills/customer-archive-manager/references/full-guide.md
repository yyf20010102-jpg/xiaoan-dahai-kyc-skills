## 指令列表

### 1. 新增客户档案

**触发指令**：
- "新增客户档案"
- "保存客户档案"
- "存储客户[姓名]的档案"

**流程**：
1. 用户提供客户基础信息（或从已完成KYC导入）
2. 系统自动分配档案编号
3. 保存到档案库
4. 返回档案编号和确认信息

**示例**：
```
用户：新增客户档案，姓名李明，45岁，企业主
AI：收到，为李明创建档案。
      档案编号：006
      客户类型：企业主
      建档时间：2026-03-26
      状态：已建档（待完善）
      
      是否现在补充详细信息？
```

---

### 2. 查询客户档案

**触发指令**：
- "查询客户档案"
- "调取[编号/姓名]的档案"
- "查看[客户名]的信息"
- "档案列表"

**查询方式**：

| 查询维度 | 指令示例 | 说明 |
|---------|---------|------|
| **按编号** | "调取006号档案" | 精确查询 |
| **按姓名** | "查看李明的档案" | 模糊匹配 |
| **按类型** | "列出所有企业主" | 类型筛选 |
| **按状态** | "显示待跟进的客户" | 状态筛选 |
| **全部列表** | "档案列表" / "所有客户" | 统计概览 |

**返回格式**：
```
档案编号：006
客户姓名：李明
客户类型：制造业企业主
资产规模：年营收5000万
建档日期：2026-03-26
跟进状态：已建档，待见面
关键标签：家企隔离、二代接班

[查看完整档案]
[修改档案]
[删除档案]
```

---

### 3. 修改客户档案

**触发指令**：
- "修改[编号/姓名]的档案"
- "更新[客户名]的[字段]"
- "[编号]的[信息]改为[新内容]"

**可修改字段**：
- 基础信息（姓名、年龄、职业等）
- 财务状况（收入、资产、负债等）
- 家庭结构（婚姻、子女、父母等）
- 健康情况（体检异常、既往症等）
- 跟进状态（待见面/已面谈/已投保等）
- 关键标签（添加/删除标签）

**示例**：
```
用户：006号的年收入改为60万
AI：已更新006号档案（李明）
      修改字段：年收入
      原值：50万
      新值：60万
      修改时间：2026-03-26 15:30
      
      是否同步更新保额建议？
```

---

### 4. 档案统计与筛选

**触发指令**：
- "档案统计"
- "客户统计"
- "按[类型/状态]筛选"

**统计维度**：
- 总客户数
- 按客户类型分布
- 按资产规模分布
- 按跟进状态分布
- 本月新增数

**返回示例**：
```
档案统计（截至2026-03-26）

总客户数：5

按类型分布：
- 企业主：2
- 金融从业者：2
- 自由职业：1

按资产规模：
- 高净值（10亿+）：2
- 中产（30-50万/年）：2
- 企业级（年营收2亿+）：1

按跟进状态：
- 已完成：4
- 待完善：1
```

## 档案结构规范

### 档案编号规则

**格式**：`XXX-客户姓名[-来源]-客户类型`

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| XXX | 3位数字序号 | 001, 002, 003... |
| 客户姓名 | 真实姓名或化名 | 张伟、王林 |
| 来源（可选） | 介绍人/渠道 | 唐思思介绍 |
| 客户类型 | 简要分类 | 企业主、私募投资人 |

### 档案文件命名

```
001-张伟-KH001-企业主.md
002-唐思思的某客户-KH002-私募投资人.md
003-张伟-KH003-秘书.md
004-刘备夫妇-KH004-企业主.md
005-王林-自媒体UP主.md
```

## 使用示例

### 场景1：新增客户并查询

```
用户：新增客户档案，张总，50岁，房地产老板
AI：已创建新档案
      档案编号：006
      客户姓名：张总
      客户类型：房地产企业主
      建档时间：2026-03-26
      状态：已建档（待完善）
      
用户：查看006号档案
AI：[显示006号档案详情]

用户：更新006号的年收入为5000万
AI：已更新006号档案
      修改字段：年收入
      新值：5000万
```

### 场景2：批量查询与筛选

```
用户：档案列表
AI：[显示所有客户统计表]

用户：列出所有企业主
AI：企业主客户（3个）：
      - 002-张伟-KH001
      - 004-刘备夫妇-KH004
      - 006-张总

用户：显示待完善的客户
AI：待完善客户（1个）：
      - 003-唐思思的某客户-KH002
```

### 场景3：修改与跟进

```
用户：004号的状态改为已见面
AI：已更新004号档案（刘备夫妇）
      修改字段：跟进状态
      原值：已建档，待见面
      新值：已见面，待方案确认
      
用户：给005号添加标签"高优先级"
AI：已为005号档案（王林）添加标签：高优先级
      当前标签：离异、自媒体、传承焦虑、亚健康、高优先级
```
