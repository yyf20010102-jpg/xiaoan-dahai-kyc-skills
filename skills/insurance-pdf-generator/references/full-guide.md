# PDF生成器

> 客户保险规划档案 PDF 快速生成工具
> 版本：1.0 | 创建：2026-05-14

## 触发条件

当用户说以下指令时激活：
- "生成 PDF" / "导出 PDF" / "做成 PDF"
- "发我 PDF 版" / "PDF 版本的方案"
- "快速生成档案 PDF"
- 任何将保险规划方案输出为 PDF 文件的需求

## 核心价值

将客户保险规划方案（Markdown 格式）快速转换为专业的 PDF 档案。内置：
- 中文字体配置（macOS 开箱即用）
- 专业配色方案和排版样式
- 表格、封面、页脚等可复用组件
- 标准化的档案页面结构

**预计耗时**：熟练使用后 3-5 分钟即可完成一个客户的 PDF 生成（vs 从零写脚本 20-30 分钟）。

## 使用流程

### 第一步：确认客户数据

确保已有该客户的保险规划方案 Markdown 文件。通常位于：
- `{workspace}/cases/{客户名}-保险配置方案.md`

如果没有，先基于 KYC 分析结果生成方案 Markdown。

### 第二步：生成 PDF 脚本

1. 读取模板脚本：`{skill_dir}/scripts/pdf_template.py`
2. 复制为 `{workspace}/generate_{客户拼音}_pdf.py`
3. 替换客户专属数据（见下方「需要替换的变量清单」）
4. 根据客户方案内容调整 story（页面内容）

### 第三步：运行脚本

```bash
cd {workspace} && python3 generate_{客户拼音}_pdf.py
```

### 第四步：交付

1. 预览确认 PDF 质量
2. 使用当前环境支持的文件附件或可点击本地文件链接交付给用户
3. 调用「大海和小安的档案管理技能」存入客户档案

## 标准页面结构（8页）

1. **封面**：客户名、档案编号、核心信息卡片、风险等级、标签
2. **客户画像**：基础信息表、家庭结构、现有保障、健康状况
3. **需求分析**：人生事件表、隐性焦虑、风险矩阵、财务脆弱性
4. **保障方案设计**：四层保障总览表、预算评估
5. **各层级详细配置**：惠民保、百万医疗、重疾险（含保额计算表）
6. **补充保障**：意外险、母亲方案、完整家庭预算表
7. **客户宝典洞察**：反常识话术、面谈话术路径表、注意事项
8. **实施路径**：分阶段实施表、跟进计划表、档案信息

## 技术栈

- **Python**：reportlab 库（PDF 生成）
- **字体**：macOS 系统自带 STHeiti Medium.ttc
- **页面**：A4，20mm 边距
- **中文支持**：通过 TTFont + subfontIndex=0 注册 TTC 字体

## 字体排查备忘

macOS 可用中文字体路径（按优先级）：
1. `/System/Library/Fonts/STHeiti Medium.ttc` — 华文黑体（推荐，必定存在）
2. `/System/Library/Fonts/Supplemental/Songti.ttc` — 宋体
3. `/System/Library/Fonts/Supplemental/STHeiti Light.ttc` — 华文黑体细体
4. `/Library/Fonts/Arial Unicode.ttf` — Arial Unicode（如已安装）

如果 STHeiti Medium.ttc 不存在，运行：
```bash
find /System/Library/Fonts -name "*.ttc" -o -name "*.ttf" 2>/dev/null | head -20
```

## 可复用组件清单

模板中预置以下函数，可直接调用：

| 函数 | 用途 | 参数 |
|------|------|------|
| `make_table(headers, rows, col_widths)` | 带样式的表格 | 表头列表、数据行列表、列宽数组 |
| `section_header(title)` | 章节标题+下划线 | 标题文字 |
| `bullet_list(items)` | 圆点列表 | 文字列表 |
| `add_page_number(canvas, doc)` | 页脚页码 | canvas 和 doc 对象 |

## 注意事项

1. **reportlab Table 没有 `.style` 属性**，要用 `table.setStyle(TableStyle([...]))` 而不是 `table.style = ...`
2. **TTFont 注册 TTC 字体需要 subfontIndex=0**
3. **页面内容过多时**，删减 bullet 项目或缩小字号，避免溢出
4. **封面客户名用大字号**（fontSize=36），独立 ParagraphStyle
5. **合计行高亮**：用 BACKGROUND 设置蓝色底色 + 去掉 ROWBACKGROUNDS 的条纹
